# 引擎用法（lib.js）和踩过的坑

> 什么时候读：写 index.html 的 seek(t) 时。先打开 `assets/examples/` 里离这句最近的一条照着改，比从空白模板写快。

## 一、原理

每条镜头是一张 1080x1920 的网页。`seek(t)` 根据时间 t（秒）把每个元素摆到该在的位置，`scripts/render.py` 从 0 到 T.end 每 1/30 秒调一次 seek、截一张图、拼成视频。所以：

- 所有动画都写成「t 的函数」，不用 CSS transition、animation、setTimeout、requestAnimationFrame，否则截出来的帧不对。
- 随机数用 `rng(种子)`，不用 Math.random，否则每次渲染不一样。
- 页面最后一行是 `ready();`：它等三种字体加载好才开始截图，别删。

## 二、常用函数（都在 lib.js 里）

| 函数 | 做什么 |
| --- | --- |
| `useStyle('paper', {accent:'#e8590c'})` | 选风格（paper / swiss / aurora / pastel / chalk），可选换强调色。必须在 `makeBackground`、`svgSetup` 之前调 |
| `prog(t,a,b)` | t 在 a 到 b 之间走到几成（0 到 1） |
| `eOut / eIn / eIO / eBack` | 先快后慢 / 先慢后快 / 两头慢 / 弹一下 |
| `flash(t,a,rise,decay,base)` | 闪一下再落回 base |
| `pulse(t,a,dur)` | 0→1→0，做往上冲又落回、轻微放大 |
| `place(el,x,y,s)` | 以中心点摆 DOM 元素 |
| `makeBackground(seed).draw(t)` | 当前风格的背景，seek 里第一行调 |
| `chrome(t)` | 开场淡入、左上角小标签、字幕预览，seek 里第二行调 |
| `svgSetup()` | 建发光、粉笔毛边滤镜，画线前调一次 |
| `growLine(x1,y1,x2,y2,{color,width,parent}).set(p)` | 一段画出来的直线，带线头；`parent: $('fxTop')` 画在卡片上面 |
| `growRing().set(cx,cy,r,p)` | 描出来的圆环（时钟、进度） |
| `growPath(d).set(p)` | 描出来的任意路径；卡框用 `rrPath(x,y,w,h,r)`，对勾用 `checkPath(cx,cy,大小)` |
| `shockwave().set(t,a,cx,cy,r0)` | 一圈往外扩的波 |
| `hitFlash(parent).set(t,a,cx,cy)` | 结论落定时闪一下（深色风格是一道光，浅色风格是一圈线往外散） |
| `along(pts,p)` | 沿折线走的点，返回坐标 |
| `slam(el,t,a)` | 大字砸下 |
| `popIn / wipeIn / blurIn` | 弹出 / 从左擦出 / 模糊淡入 |
| `dimOut(el,t,a)` | 变暗变灰退下（旧的被否掉以后） |
| `typeText(el,text,t,a)` | 打字带光标 |
| `countTo(el,from,to,t,a,dur)` | 数字滚动 |
| `stampIn(el,t,a)` | 盖印章（`.stamp` 元素） |
| `blink(t)` | 小灯闪烁的亮度 |

常用的样式类：`.card`（卡片，`.card.hot` 是点亮的那张）、`.chip`（胶囊标签）、`.heavy`（特粗大字）、`.w` / `.a`（双色标题的前半 / 后半）、`.warn`（红字）、`.label`（小标签）、`.stamp`（印章）。每套风格下它们长得不一样，写一次换风格就跟着变。

## 三、踩过的坑

1. **水平线、竖线加了发光就消失。**SVG 滤镜默认按图形包围盒算，横竖线包围盒是 0。`svgSetup()` 已经用 `userSpaceOnUse` 修好，自己另写滤镜时也要这样写。
2. **全局写 `svg{position:absolute}` 会把卡片里的小图标甩到左上角。**只给 `#fx`、`#fxTop` 写绝对定位。
3. **元素出现在半空。**`place()` 以中心对齐；卡片用 `left/top` 以左上角对齐，两种别混着算。
4. **卡片里的对勾、图表线看不见。**`#fx` 在所有卡片下面，画在卡片范围里的线会被盖住，改画到 `#fxTop`：`growPath(d, { parent: $('fxTop') })`。
5. **中文大字用了别的字体。**大字加 `class="heavy"`（思源黑体特粗，模板带了字体文件）；正文默认思源黑体，黑板风格用霞鹜文楷。字体文件在镜头文件夹的 `fonts/` 里，别删。少数生僻字字体里没有，会用电脑自带字体顶上。
6. **换了风格，颜色写死的地方没跟着变。**颜色一律写 `var(--accent)`、`var(--warn)`、`var(--text)`、`var(--dim)`，或者 JS 里的 `S.accent`、`S.warn`，不写死色值。
7. **点亮的卡片（`.card.hot`）上的对勾、圆圈看不见。**白底网格风格的点亮卡片是整块强调色，画在上面的线要用 `color: S.onHot`（这套是白色，别的风格就是强调色）。

## 四、加一套自己的风格

在 `lib.js` 的 `STYLES` 里照现有的复制一套改：`bg` 两个颜色是上下渐变，`bgKind` 选背景画法（paper 点阵 / swiss 网格 / aurora 色块加扫描线 / pastel 柔和色团 / chalk 粉笔灰），`light` 浅色底写 true，`glow` 是线条发光强度（0 不发光），`css` 里写卡片、标题在这套风格下的样子。改完用 `render.py <例子> --style 新名字 --frames 30,90,150` 看三个例子在新风格下是不是都对。
