# 演法对照表：口播在说什么 → 用什么画面演

> 什么时候读：给每一句挑演法之前（流程第 2 步）。
> 原料：视频号上讲 AI 产品、点赞 1000 以上的 7 条口播，2026 年 11 月逐 0.1 秒拆出来的。括号里「朋克周 80 秒」指那位博主那条视频的第 80 秒，想看原样可以去他的视频号找来看；这里只记做法，不放别人的画面。

## 一、这些视频什么时候用 UI 动效

- UI 动效在每条里占 11% 到 40%。画面主力是手持手机拍屏和录屏，博主出镜很少，朋克周、菩提猫、阑夕全片没露脸。
- 7 条里赞数最高的赛文乔伊（16502 赞），UI 动效占比也最高（40%，全屏动效约 48 秒）。这只是两件事同时出现，不能说明是动效带来的赞。
- 分工很固定：**演示「我用它做了什么」用实拍和录屏，讲「它是什么、为什么、怎么做到的」才切 UI 动效。**林亦、朋克周都是这样：暖色实拍一切到冷色动效，观众就知道在讲原理了。
- 所以 UI 动效要接的是口播里抽象、看不见的那几句：概念定义、前后对比、列举、数量、时间上的持续、规则和步骤。能直接录屏演示的句子不用它。

## 二、口播在说什么 → 用什么画面演

## 三、怎么借，不照搬

一句话：「参考走这个，不过不能和他一样」。借的是**结构**（什么概念配什么动作、动作的先后和节奏），换掉**主角、布局、配色**：

- 借法示意：赛文乔伊用「聊天气泡被红线划掉，三张能力卡立起」讲「不是聊天机器人，而是管事 AI」；你要讲「以前剪一条视频要三天，现在一个下午」，借「旧的划掉变暗、新的搭起来、大字砸下」这个结构，主角换成你自己的事：三天的日程块、一圈转满的时钟（`assets/examples/对比_划掉换新/`）。
- 差的：照着赛文乔伊的三张金框卡、同样的「记得住 / 盯得住 / 办得了」重画一遍，只换了颜色。观众一眼看出是照着谁做的。
- 差的：口播里没有的东西硬塞进画面。菩提猫有一张卡「迈开腿管住嘴」口播里根本没说，观众会对不上。

## 四、这句该不该做成 UI 动效

| 这句话 | 做不做 | 原因 |
| --- | --- | --- |
| 讲概念、定义、原理（「啥叫个人 agent」） | 做 | 看不见的东西，只能画出来 |
| 前后对比、不是 A 而是 B | 做 | 对照表里有成熟结构 |
| 列举、数量、金额、时间上的持续 | 做 | 数字滚动、逐个弹出、时间轴最出效果 |
| 规则、步骤、判断标准 | 做 | 清单、流水线、闸门 |
| 「我打开 App，输入一句话」这类操作演示 | 不做 | 录屏、拍屏更可信，直接用录屏，最多加个圈或箭头标重点 |
| 讲自己的经历、情绪 | 不做 | 博主出镜或实拍更有人味 |
