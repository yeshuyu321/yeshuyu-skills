# 输出模板

> 什么时候读：写资料卡、骨架、每段逐字稿、完整稿、念稿版、提词卡之前，读对应的那一节。
> 来源标记三种：`[你说的]` 用户原话或资料里有；`[我猜的，待你确认]` AI 推测、用户还没确认；`【待补】` 没有，要用户自己补真的。

## 资料卡

```markdown
# 资料卡：{推的东西}

0. 现场怎么称呼你：{……} [你说的]
1. 推什么：{……} [你说的]
2. 讲完希望对方做什么：{……} [你说的]
3. 在哪讲、多少人、讲多久：{……}
4. 听的人是谁：{一个具体的人} 
5. 他们最头疼 / 最想要：{……}
6. 他们为什么犹豫：{……}
7. 价格和福利：{价格}；{今天才有的优惠}；{名额 / 截止时间}
8. 凭什么找你：{……}
9. 你的故事：以前 {……} → 转折 {……} → 现在 {……}
10. 别人的真实变化：{谁} 以前 {……}，现在 {……}

还缺：{列出所有【待补】}
```

每条后面都要带来源标记。用户没确认的猜测，写进稿子前必须改成用户确认过的说法。

## 骨架

```markdown
# 主线：{用户选定的那一句}

总时长：{n} 分钟

| 段落 | 时长 | 讲什么 | 用哪条素材 | 还缺 |
|---|---|---|---|---|
| 开场留住人 | {n} 分钟 | {一两句} | 资料卡第 {x} 条 | {无 / 待补什么} |
| 打破一个误区 | | | | |
| 讲故事证明 | | | | |
| 让人信任你 | | | | |
| 介绍产品和价格 | | | | |
| 告诉他现在怎么做 | | | | |

互动安排：第 {n} 分钟问「……」；第 {n} 分钟问「……」
```

## 每一段逐字稿

```markdown
## {段名}（约 {n} 分钟，{字数} 字）

{逐字稿，短句，一行一句或一小段}

【停顿】
【互动：……有的扣 1】
【待补：这里放一个……】

> 这段为什么这么写：{一句话}

回「继续」写下一段；回「改短一点」或「换个说法」，我改这一段。
```

## 完整稿

六段按顺序连起来，段与段之间加一句过渡（例：「讲完我自己，我们来看一个跟你很像的人。」），保留所有标记和段名。

## 念稿版

- 去掉段名以外的所有说明、「这段为什么这么写」、来源标记
- 保留【停顿】【互动】
- `【待补】` 改成醒目的 `【讲之前补：……】`
- 每句单独一行，方便边看边念

## 提词卡

```markdown
# 提词卡：{推的东西}（总长约 {n} 分钟）

讲之前必须补上：
- {待补 1}
- {待补 2}

| 段落 | 时长 | 提醒自己 | 这句一定要说出口 |
|---|---|---|---|
| 开场留住人 | {n} 分钟 | {一句提醒} | 「……」 |
| 打破一个误区 | | | |
| 讲故事证明 | | | |
| 让人信任你 | | | |
| 介绍产品和价格 | | | |
| 告诉他现在怎么做 | | | |

最后一句：{收尾时要说的行动指令，含截止时间和怎么做}
```

「这句一定要说出口」选这一段最有力的一句：主线、故事里最打动人的那句、行动指令。不选免责、客套、过渡的句子。
